## 第二步：不可违反的技术事实

这些是我在本机 DSH 0.2.1-rc.3 实机核对过的结论，**不要再自己重新推导，也不要凭印象改**。如果与你的记忆冲突，以本清单为准。

### 运行环境
- DSH `0.2.1-rc.3`（macOS 桌面版），profile 在 `~/.dsh/profiles/desktop`
- 开发 shell Node `v22.23.2`，桌面 runtime 自带 Node `24.21.0`，pnpm `11.28.5`
- `node:sqlite` 在 Node 22 可 import 但带 ExperimentalWarning —— 我们不用，用 JSON

### 插件形态（三件套）
- 宿主半：`package.json` 的 `main` / `exports["."]`，在 DSH 主进程执行 `apply(ctx, config)`
- 客户端半：`exports["./client"]` + `dsh.client.platform = "web"`
- 配置层：`dsh.bundle.patch` 指向 `cordis.patch.yml`，格式为 `- insert: [{id, name, config}]`
- 客户端 bundle 必须手写为：
  ```js
  window.__ModuleLoader__.load({
    id: 'dsh-todos-diy',           // 必须严格等于包名
    factory(require) {
      const React = require('react');   // 只能 require 平台冻结表里的模块
      return { inject: ['slots','locale'], apply(ctx) { /* ... */ } };
    },
  });
  ```
- `dsh.client.immediately: true` **只做首屏预取**（`prefetchImmediateTier()` → `modules.prefetch()`），**不决定**插件是否激活。已启用的客户端插件在 boot 阶段都会 create。设不设不影响浮层常驻。

### 客户端 slot（已核对 ui-schedule 的实际用法）
| slot | 注册参数 |
|---|---|
| `sidebar.panellist` | `{name:'sidebar.panellist', id:'todos-diy', order:30, label:()=>t('entry.label')}` |
| `main` | `{name:'main', key:'todos-diy', locale:'todos-diy'}` |
| `shell.overlay` | `{name:'shell.overlay', id:'todos-diy-overlay', order:60, locale:'todos-diy'}` |

`sidebar.panellist` 的 `id` 必须等于 `main` 的 `key`。

### 宿主服务（易错点）
- **`ctx.locale` 只在客户端存在**（由 `dsh-client-locale` 的客户端插件 `ctx.provide("locale")`）。宿主半调用会得到 `undefined`。宿主返回错误码，客户端用字典翻译。
- `ctx.interval(cb, ms)` 来自 `cordis-plugin-timer`，返回 disposer，随 fiber 自动清理
- `ctx.effect(fnOrDisposer, label)` 管理资源
- 路由：`ctx.webServer.register({kind:'exact', path:'/api/dsh-todos-diy/...', handler})`
- **路由准入必须显式委托** `connection.requestRejection({headers: req.headers})`（返回 `undefined`/`401`/`403`）。exact 路由先于官方 `/api` prefix 匹配，不委托就等于无鉴权。`connection` 缺失时回退纯回环检查。
- 工具：`ctx.tools.register(defineTool({...}))` 或原始 JSON Schema

### 兼容声明（这一条踩过坑）
- `engines.dsh` 由 `dsh-app-boot` **强制校验**：声明了就只按它判定、忽略 peerDependencies，不满足直接拒绝加载（`incompatible-version`）
- 求值用 `semver.satisfies(runtime, range, {includePrerelease: true})`
- **只写 `"^0.2.1-rc.3"`**。不要写 `>=0.2.0-rc.1 <0.3.0` 这类宽范围，也不要堆一长串旧预发布 comparator
- 不声明 `peerDependencies`，零 `dependencies`，宿主半不 import 任何 `@deepseek-ai/*`

### 命名与路径（全文统一，不得改）
| 项 | 值 |
|---|---|
| 包名 | `dsh-todos-diy` |
| loader 行 id | `todos-diy` |
| 客户端 bundle id | `dsh-todos-diy` |
| HTTP 前缀 | `/api/dsh-todos-diy` |

不要用 `dsh-todo-reminder`（本机已装同名插件，会冲突）或 `dsh-todos`（也已安装）。

## 第三步：已拍板的产品决策（不要再问，直接实现）

| 编号 | 决策 |
|---|---|
| D-01 | **自研轻量调度**，不依赖内置 `ctx.schedule`，自管持久化 |
| D-02 | **不接入 Agent 会话**：只有 `shell.overlay` 浮层（必有）+ 浏览器系统通知（可选） |
| D-03 | 单次任务默认**起止都提醒**：`startAt` 可省略（默认 `createdAt`，不产生开始提醒）、`endAt` 必填；显式 startAt 时开始/结束各一次，各独立 occurrence（`#start`/`#end`）；会议类可 `notify.endReminder=false` 只提醒开始 |
| D-04 | 「工作日」**跟随中国法定节假日与调休**（内置 `assets/holidays-cn-2024-2027.json`，`holidayCalendar:"CN"` 默认，可切 `"none"`） |
| D-05 | 每月 29–31 日不存在时**顺延到当月最后一天**（`monthlyOverflow:"lastDay"` 默认，可切 `"skip"`） |
| D-06 | 错过策略：`graceMinutes=5` 内补触发一次，超过标 `missed` **不补发** |
| D-07 | **任务不绑定会话**，无 `sessionId` 字段 |
| D-08 | 循环任务只有 `pause`/`resume`，**不设结束日期/次数上限** |
| D-20 | 优先级**纯派生**：单次按 `endAt`、循环按 `nextAt` 实时算、只读、不落盘；`paused` 返回 `priority.key="paused"` |
| D-21 | **超期任务仍置顶**（置顶组永远最上方，带「超期」红标） |
| D-22 | **暂停 = 主动搁置**：不算超期、不参与优先级、独立筛选，不混入任何阶段页签 |
| D-23 | 持久化：**单 JSON 原子写**（tmp + rename），不用 SQLite |
| D-24 | 已完成任务**永久保存**；主文件只留本季度，跨季度移入 `archive/completed-YYYY-Qn.json` + `index.json` |
| D-25 | **删除 `dueDate`**；单次 `startAt` 可选（默认 `createdAt`，默认开始节点不提醒）+ `endAt` 唯一截止；`stage` 读时派生，循环任务独立 `recurring`；取消 `endAt` 自动 `done`；取消 00:05 状态重算 |

### 优先级规则（务必按这个实现）
```
remainingMs = endAt − now（单次任务）；nextAt − now（循环任务）
now > endAt 或 remainingMs ≤ 24h  → 高
24h < remainingMs ≤ 72h           → 中
72h < remainingMs ≤ 168h          → 低
> 168h 或无目标                    → 无
paused                             → 已暂停（不参与计算）
```
按当前时刻实时计算，不落盘、不设 00:05 重算。排序：`pinned → 优先级 → 结束时间（循环按 nextAt）`。

### 四阶段页签 + 循环/暂停筛选（D-25）
- **未开始** = `active` 且 `kind=once` 且 `now < startAt`
- **进行中** = `active` 且 `kind=once` 且 `startAt ≤ now < endAt`
- **已超期** = `active` 且 `kind=once` 且 `now > endAt`（当秒算进行中）
- **已完成** = `done`（仅单次任务可 done），默认本季度；可切历史季度归档
- **循环任务** = 独立筛选，`stage="recurring"`，显示下次触发，不计入四阶段徽标
- **已暂停** = 独立筛选/折叠区，不混入任何阶段页签

## 第五步：编码约定

- 宿主半 TypeScript（`strict: true`），编译到 `lib/`；客户端可用 TS 编译或手写 JS，产物必须是 `lib/client.js`
- 纯函数与 IO 严格分离：`rules/*` 不碰 `fs`、不取系统时间
- 所有定时器/路由/工具注册都用 `ctx.effect` 包裹并返回 disposer
- 日志用 `ctx.logger`，前缀 `todos-diy:`，**不打印任务说明全文**（只打印 id 与标题前 20 字符）
- 客户端只用 `--dsw-alias-*` 主题 token，不写字面色值（图形除外）
- 中文文案，代码/字段/API 英文
