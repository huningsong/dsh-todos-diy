# 工程配置与脚本

> 目的：说明仓库根目录为什么保留这些配置文件，以及哪些东西应该放 `docs/`、哪些必须留在根目录。

## 1. 根目录配置（不要移动）

| 文件 | 作用 | 为什么留在根目录 |
|---|---|---|
| `package.json` | 包名、版本、`main`/`exports`、`dsh.bundle`、`dsh.client`、`engines`、`files`、scripts | Node/npm/pnpm 与 DSH marketplace 都按根目录识别；`files` 白名单也以根为基准 |
| `tsconfig.json` | 宿主半构建配置：`src/host/**/*.ts` → `lib/` | `tsc -p tsconfig.json`、编辑器/IDE 默认识别根 `tsconfig.json`；`rootDir: "src/host"`；保留在根目录作为 IDE 入口 |
| `config/tsconfig.client.json` | 客户端半类型检查配置：`src/client/**/*.ts` | 与宿主分离，客户端依赖 DOM/React 类型；脚本 `tsc -p config/tsconfig.client.json` |
| `config/tsconfig.test.json` | 测试编译配置：`src/host` + `test` → `.test-build/`，供 `node --test` 执行 | 继承根 `tsconfig.json`，`rootDir: ".."` 指回仓库根；脚本显式用 `-p config/tsconfig.test.json` |
| `cordis.patch.yml` | DSH bundle patch：`- insert: [{id: todos-diy, name, config}]` | `package.json` 的 `dsh.bundle.patch` 指向根目录；插件安装器按根路径读取 |
| `pnpm-workspace.yaml` / `pnpm-lock.yaml` | pnpm 工作区与锁定版本 | pnpm 要求根目录；锁文件必须随仓库提交 |
| `screenshots.json` | 市场截图清单（1–8 个相对路径） | DSH 市场读取仓库根文件；不能放进 `docs/` 子目录 |
| `.gitignore` / `LICENSE` / `README.md` / `CHANGELOG.md` | 仓库入口与元数据 | 平台/用户默认在根目录查找 |

> 结论：**`tsconfig.json`、`package.json`、`cordis.patch.yml` 这类“工具链入口”不建议归档到 `docs/`**；客户端/测试 tsconfig 已归入 `config/`，根目录只保留 IDE 入口 `tsconfig.json`。

## 2. 该归类的目录

| 目录 | 放什么 | 不放什么 |
|---|---|---|
| `src/` | 插件源码（host/client） | 文档、截图、构建产物 |
| `test/` | 单元测试与测试夹具 | 源码、文档 |
| `lib/` | **构建产物**（tsc/esbuild 输出，已 gitignore） | 手写代码 |
| `.test-build/` | **测试编译产物**（gitignore） | 手写代码 |
| `dist/` | 历史打包产物（`*.tgz`，gitignore 的 `*.tgz`） | 源码 |
| `config/` | 客户端/测试的 tsconfig（工具链配置） | 文档、运行时代码 |
| `docs/` | 需求、决策、评审、计划、测试记录、指南、市场物料 | 运行时代码、构建配置 |
| `assets/` | 随包静态资源（节假日表、图标） | 文档 |
| `locale/` | 插件 UI 字典 | 文档 |
| `scripts/` | 构建/打包/校验脚本 | 业务实现 |

## 3. 本仓库的归类规则

1. **根目录只保留“工具链入口”**：包清单、tsconfig、DSH patch、lockfile、README/CHANGELOG/LICENSE、市场 `screenshots.json`。
2. **所有说明性文档进 `docs/`**：需求、决策、评审、版本计划、测试记录、开发提示词、市场指引。
3. **构建/测试产物不进 git**：`lib/`、`.test-build/`、`dist/*.tgz` 由 `.gitignore` 覆盖。
4. **文档索引统一在** [`docs/README.md`](../README.md)；新增文档必须加索引与轮次记录。
5. **代码不改目录结构**：`src/host`、`src/client`、`test` 已按职责分离，避免为了“看起来整齐”破坏相对 import。

## 4. 常用命令

```bash
pnpm build       # scripts/build.mjs：tsc host + esbuild client → lib/
pnpm typecheck   # tsconfig.json + config/tsconfig.client.json
pnpm test        # config/tsconfig.test.json → .test-build/ → node --test
pnpm verify      # typecheck + test + scripts/verify-pack.mjs
```

> 当前环境 `pnpm verify` 可能被 `allowBuilds` / `ignoredBuilds` 拦截；CI 使用 `tsc ...` 与 `node --test` 直调，详见 [测试记录](../testing/测试记录.md)。
