## 2. 修复建议

### FIX-07（P2-1）单次任务不再显示「下次」

`src/client/task-row.ts`：

```ts
const nextText = task.kind === 'recurring' && task.nextAt !== null
  ? t('task.nextAt', { time: formatInZone(task.nextAt, task.timeZone) })
  : null
```

右侧渲染改为：
- 单次任务：只显示 `due.text`（截止 …）
- 循环任务：保留 `due.text` + `nextText`
- 已暂停：仍显示 `priority.paused`

**验收**：单次任务行只出现一次时间；循环任务仍显示「下次 …」。

### FIX-08（P2-2）搜索无结果独立空态

- `TaskListProps` 增加 `search: string`；
- `panel.ts` 的 `buildTaskListProps()` 传入当前 `search`；
- `task-list.ts` 空态分支：
  ```ts
  if (props.items.length === 0) {
    if (props.search.trim() !== '') return h(NoMatch, { query: props.search })
    return existingEmptyState
  }
  ```
- 新增字典：
  - `empty.noMatch`: `没有找到匹配“{query}”的任务`
  - `empty.clearSearch`: `清除搜索查看全部`
- **验收**：在 30 条「未开始」中搜不存在词 → 显示「没有找到匹配“xxx”的任务」+ 清除搜索按钮；清空关键词恢复 30 条。

### P2-3：暂不修

当前量级不是性能问题；不要为了 30/类引入虚拟滚动。等单视图 >300 条时再评估。

### 置顶功能：不是 bug

- 代码存在：`task-row.ts` 的 `onPin`、`PinGlyph`、`aria-label=置顶/取消置顶`；
- 仅在 hover/focus 显示，符合 UX-03「行内三按钮」；
- 若要更易发现：在「更多」菜单增加「置顶 / 取消置顶」一项（不改主交互），或在 pinned row 的右侧 always show filled pin。

### 数据清理：先备份再清理

当前 185 条中约 180 条是第三轮测试数据。建议：
1. 先备份 `~/.dsh/dsh-todos-diy/tasks.json`；
2. 只删除标题前缀为 `[未开始]`、`[进行中]`、`[已超期]`、`[已完成]`、`[循环]`、`[已暂停]` 的测试任务；
3. 保留原有 5 条（如「飞书日报填写」「测试1」等）；
4. 以后 UI 批量测试使用临时 profile/临时 `DSH_HOME`，不要污染真实库。
