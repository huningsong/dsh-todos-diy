## 3. R3/D-25 测试计划

### 3.1 必测 10 类

1. `stage` 六态与时间边界（`now == startAt` / `now == endAt` / `endAt+1ms`）；
2. 四阶段页签互斥（1/2/1/4 样本）；
3. `counts/byKind/totalDone` 与「筛选数字 = 页签条数」；
4. `startAt` 省略 → `createdAt` + `startAtSource="created"` + 无 `#start`；
5. `endReminder=false` → 只 `#start`；无显式 `startAt` → `invalid_argument`；
6. `endAt` 后仍 `active`、`stage="overdue"`、不自动 `done`；
7. 迁移 v1→v2（主文件 + archive quarter + index + import）；
8. `serverTime` / `nextTransitionAt` 与边界刷新；
9. 日期-only `endAt=23:59:59.999`（任务时区）；
10. 优先级 24h/72h/168h ±1ms 边界。

### 5.1 工具数量变更（偏差记录）

规划稿 §2.2 F7.14 + F7.17 实际新增 **3 个**工具（`get`、`remind`、`deliveries`），总数应为 **9 → 12**；规划稿「工具总数从 9 增加到 11」为笔误。已按实际实现 12 个并在 `/health.capabilities.agentTools` 动态反映。
